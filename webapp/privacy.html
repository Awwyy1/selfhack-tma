Политика конфиденциальности

Последнее обновление: 27 ноября 2024

SelfHack ("мы", "наш", "приложение") — AI-коуч в Telegram. Мы серьёзно относимся к защите ваших данных.

1. Какие данные мы собираем

  • Telegram ID — для идентификации аккаунта
  • Сообщения в чате — для персонализации коучинга
  • Цели и чекины — для отслеживания прогресса
  • Настройки — выбранный стиль коуча, тема

2. Как мы используем данные

  • Предоставление персонализированного коучинга
  • Сохранение истории разговоров
  • Отправка напоминаний (если вы их настроили)
  • Улучшение качества сервиса

3. Кто имеет доступ к данным

Ваши данные обрабатываются:

  • Anthropic Claude API — для генерации ответов AI
  • Supabase — для хранения данных
  • Vercel — для хостинга приложения

Мы не продаём и не передаём ваши данные третьим лицам.

4. Безопасность

Мы используем:

  • Шифрование при передаче данных (HTTPS)
  • Защищённые серверы с ограниченным доступом
  • Регулярное обновление систем безопасности

5. Хранение данных

  • История сообщений: 30 дней (Premium) / 7 дней (Free)
  • Цели и чекины: пока вы не удалите
  • Аккаунт: пока вы не удалите

6. Ваши права

Вы можете в любой момент:

  • Удалить все данные — Профиль → "Удалить все данные"
  • Запросить копию данных — напишите в поддержку
  • Отозвать согласие — просто удалите данные

7. Дети

Приложение не предназначено для лиц младше 16 лет.

8. Изменения политики

Мы можем обновлять эту политику. О существенных изменениях сообщим в приложении.
